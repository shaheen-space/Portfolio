# Shaheen Portfolio

A responsive personal portfolio website for an Electrical & Electronics Engineering student.

## Files
- `index.html` — main portfolio
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year
- `resume.pdf` — add your own resume here

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the LinkedIn URL with your actual LinkedIn profile.
3. Add your `resume.pdf` to this folder.
4. Update the certification cards with completed certificates.
5. Review project descriptions and dates.

## GitHub Pages
Create a GitHub repository (for example `portfolio`), upload these files to the `main` branch, then open:
Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

Your site will normally be available at:
`https://shaheen-space.github.io/portfolio/`
